# P5: `sampling` Stage (Harmonic Wigner Sampling) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `sampling` stage that draws initial geometries and velocities from the harmonic Wigner distribution of the `frequencies` result. It works at T = 0 and at T > 0.
- **Momentum:** total linear and angular momentum are removed from every sample.
- **Outputs:** `samples.h5`, `samples.xyz` and `samples.json`.
- **Checks:** the sampled energy statistics are verified against theory, and the distributions are validated against SHARC 4.1 `wigner.py`.

**Architecture:**
- **Sampler (`gqteashmd.vib.wigner`).** A pure NumPy sampler. Each sampled normal mode is an independent Gaussian in mass-weighted normal coordinates (Q, P). The widths come from the exact thermal Wigner function of a harmonic oscillator. Modes below the low-frequency cutoff are not sampled; this includes any small imaginary modes the frequencies stage kept.
- **Stage.** A one-task stage reads `frequencies.h5` and draws from a seeded `numpy.random.Generator`. The seed comes from `project.seed` through `SeedSequence` (master plan D12). The stage writes the artifacts and checks:
  - the mean harmonic energy against the expected value;
  - zero momenta.
- **SHARC comparison tool.** `tools/sharc_compare` gains an `initconds` parser of our own and a seed option for the `wigner.py` runner.

**Tech Stack:** Python 3.12, NumPy, SciPy (`stats.ks_2samp`, tests only), h5py, pytest, ruff 0.17.4, mypy.

**Spec:**
- Master plan [`2026-11-06-gqteashmd-master-plan.md`](2026-11-06-gqteashmd-master-plan.md):
  - §1.1 (stage 3);
  - §3 (seeds: `SeedSequence([project.seed, crc32(stage_name)])`, and a child stream per task index);
  - §4.3 `[sampling]`;
  - §5 `sampling` row: `samples.h5` holds positions, velocities, per-mode q/p and harmonic energy, plus `samples.xyz`. The stage stops if the mean harmonic energy is not ≈ ZPE at T = 0, or if the total linear and angular momentum is not zero;
  - §7 `sampling` validation: run SHARC `wigner.py` on *our* Molden file and compare the distributions (means and variances of internal coordinates, kinetic-energy histogram, two-sample Kolmogorov–Smirnov). The comparison is not per sample;
  - D12, O4;
  - M2: from one input, the program produces optimized geometry → frequencies → Wigner samples, matching the `wigner.py` statistics.
- Strategy [`SHMD_implementation_strategy.md`](../../../SHMD_implementation_strategy.md) §4.8, Wigner sampling: mass weighting, linear molecules, imaginary modes, low-frequency modes.

**Owner decisions (2026-11-08):**
1. **O4:** T > 0 uses the exact harmonic thermal Wigner function, with widths σ_Q² = (ħ/2ω)·coth(ħω/2k_BT) and σ_P² = (ħω/2)·coth(ħω/2k_BT). It reduces to the ground state at T = 0.
2. Modes with ν̃ below `sampling.low_frequency_cutoff_cm1` (default 10 cm⁻¹, the same default as SHARC's `-L`) are **not sampled**. They keep their equilibrium coordinate and get zero velocity, and they are listed in a warning. This covers small imaginary modes.

## Facts verified before writing this plan (WSL, 2026-11-08)

1. **SHARC 4.1 `wigner.py`, executed as a black box.**
   - **Usage:** `wigner.py [options] file.molden`. The options include:
     - `-n N`;
     - `-r SEED`;
     - `-t T` (temperature);
     - `-L` (discard frequencies below this value in cm⁻¹, default 10);
     - `-o` (output name, default `initconds`);
     - `--keep_trans_rot`, `--use_eq_geom` and `--use_zero_veloc`.
   - **Our Molden file:** it reads ours without trouble. It detects our modes as "gaussian-type", warns "Less than 3*N_atom normal modes, but no [N_FREQ] keyword!", and reports "Assumed Isotopes: H-1 O-16".
   - **The `initconds` text format:**
     - Header lines: `Ninit`, `Natom`, `Repr`, `Temp`, `Eref`, `Eharm`.
     - An `Equilibrium` block with one line per atom: `symbol  Z  x y z (bohr)  mass(amu)  vx vy vz`.
     - Per sample:
       - `Index k`, then `Atoms`, then one line per atom in the same format, with velocities in bohr per atomic time unit;
       - `States`, then lines `Ekin`, `Epot_harm`, `Epot`, `Etot_harm` and `Etot` in a.u.
   - **ZPE check:** for water RHF/STO-3G (2170.05, 4140.00 and 4391.07 cm⁻¹), `Eharm` = 0.0243789326 Eh. That is exactly ½Σω.
2. **The draft sampler of Task 2 matches SHARC.** N = 20000 of ours against 2000 of SHARC's, from the same Molden file:

   | Quantity | Ours | SHARC | KS p-value |
   |---|---|---|---|
   | r(O–H₁) (bohr) | 1.87320 ± 0.12183 | 1.87280 ± 0.12251 | 0.966 |
   | r(O–H₂) (bohr) | | | 0.275 |
   | HOH angle (°) | 100.01 ± 7.44 | 100.14 ± 7.26 | 0.280 |
   | Kinetic energy, before momentum removal (Eh) | 0.012250 | 0.011957 | 0.400 |

   - The expected kinetic energy before removal is Σω/4 = 0.012189 Eh.
   - **Angular momentum:** SHARC's samples have mean |L| = 1.4·10⁻⁵ ħ, while our draft without removal had 0.55 ħ. SHARC therefore removes the rigid rotation, without rescaling the velocities; that is why its mean kinetic energy is below Σω/4. Total linear momentum is ≈ 0 in both: ours 1.5·10⁻⁸ and SHARC 2·10⁻⁴, in a.u.
   - **Ruling:** remove linear and angular momentum at every sampled geometry, without rescaling, as the spec requires. Record the removed kinetic energy.
3. **Thermal widths.** For a harmonic mode, E_k = ½P² + ½ω²Q² with Gaussian Q and P has mean ⟨E_k⟩ = (ω/2)·coth(ω/2k_BT) and variance ⟨E_k⟩². The total sampled harmonic energy therefore has mean Σ⟨E_k⟩ and standard deviation √(Σ⟨E_k⟩²). The stage check uses this: |mean − expected| ≤ 5·σ/√N.

```python
"""Reproducible random streams: one master seed (project.seed) → per-stage → per-task (D12)."""

from __future__ import annotations

import zlib

import numpy as np


def stage_seed_sequence(project_seed: int, stage_name: str) -> np.random.SeedSequence:
    return np.random.SeedSequence([project_seed, zlib.crc32(stage_name.encode("utf-8"))])


def task_rng(project_seed: int, stage_name: str, task_index: int) -> np.random.Generator:
    """The generator of task `task_index`; independent of the total number of tasks."""
    child = stage_seed_sequence(project_seed, stage_name).spawn(task_index + 1)[task_index]
    return np.random.default_rng(child)
```

```python
import pytest

from gqteashmd.core.units import BOLTZMANN_HARTREE_PER_K, DALTON_IN_ME, HARTREE_IN_CM1
from gqteashmd.vib.harmonic import harmonic_analysis
from gqteashmd.vib.wigner import mode_widths, remove_rigid_motion, sample_wigner

WATER_MASSES = np.array([15.994915, 1.007825, 1.007825])
WATER_BOHR = np.array([[0.0, 0.0, 0.28377702], [0.0, 1.43256453, -0.91771557],
                       [0.0, -1.43256453, -0.91771557]])


def _model_water():
    """A synthetic, translation/rotation-free Hessian projected into the vibrational space."""
    rng = np.random.default_rng(5)
    a = rng.normal(size=(9, 9))
    analysis = harmonic_analysis(WATER_MASSES, WATER_BOHR, a @ a.T * 0.2 + np.eye(9) * 0.3)
    return analysis


def test_widths_at_zero_and_high_temperature():
    omega = np.array([0.01, 0.02])
    sq, sp = mode_widths(omega, 0.0)
    np.testing.assert_allclose(sq**2, 1 / (2 * omega))
    np.testing.assert_allclose(sp**2, omega / 2)
    t = 1e5  # kT >> omega: classical limit <E> = kT
    sq, sp = mode_widths(omega, t)
    kt = BOLTZMANN_HARTREE_PER_K * t
    np.testing.assert_allclose(0.5 * sp**2 + 0.5 * omega**2 * sq**2, kt, rtol=1e-3)


def test_mean_energy_matches_zero_point_energy():
    analysis = _model_water()
    samples = sample_wigner(WATER_MASSES, WATER_BOHR, analysis.frequencies_cm1,
                            analysis.modes_mass_weighted, n_samples=40000, temperature_K=0.0,
                            low_frequency_cutoff_cm1=10.0, rng=np.random.default_rng(1))
    zpe = 0.5 * (analysis.frequencies_cm1 / HARTREE_IN_CM1).sum()
    assert samples.expected_mean_energy_hartree == pytest.approx(zpe, rel=1e-12)
```

```python
"""Harmonic Wigner sampling of initial conditions (independent normal modes).

For a harmonic mode of angular frequency omega (hartree, hbar = 1) the thermal Wigner function
is a Gaussian in the mass-weighted normal coordinate Q (sqrt(m_e) bohr) and momentum P:
    sigma_Q^2 = c / (2 omega),   sigma_P^2 = c omega / 2,   c = coth(omega / 2 k_B T)  (c = 1 at T = 0)
(Hillery et al., Phys. Rep. 106, 121 (1984)). Then <E> = (omega/2) c and Var(E) = <E>^2.
Cartesian displacements and velocities: dx = M^-1/2 L Q, v = M^-1/2 L P, M in electron masses.
Modes below the low-frequency cutoff (including imaginary ones) are not sampled. The total linear
and angular momentum of each sample is removed afterwards (velocities are not rescaled).
"""

from __future__ import annotations

from dataclasses import dataclass

import numpy as np
from numpy.typing import ArrayLike

from gqteashmd.core.units import BOLTZMANN_HARTREE_PER_K, DALTON_IN_ME, HARTREE_IN_CM1


@dataclass(frozen=True, eq=False)
class WignerSamples:
    positions_bohr: np.ndarray
    velocities_au: np.ndarray
    q: np.ndarray
    p: np.ndarray
    harmonic_energy_hartree: np.ndarray
    kinetic_energy_hartree: np.ndarray
    removed_kinetic_energy_hartree: np.ndarray
    sampled_modes: np.ndarray
    expected_mean_energy_hartree: float
    expected_energy_std_hartree: float


def _occupation_factor(omega: np.ndarray, temperature_K: float) -> np.ndarray:
    if temperature_K <= 0.0:
        return np.ones_like(omega)
    return 1.0 / np.tanh(omega / (2.0 * BOLTZMANN_HARTREE_PER_K * temperature_K))


def mode_widths(omega_au: ArrayLike, temperature_K: float) -> tuple[np.ndarray, np.ndarray]:
    omega = np.asarray(omega_au, dtype=float)
    c = _occupation_factor(omega, temperature_K)
    return np.sqrt(c / (2.0 * omega)), np.sqrt(c * omega / 2.0)


def _kinetic(masses_me: np.ndarray, velocities: np.ndarray) -> np.ndarray:
    return 0.5 * (masses_me[None, :, None] * velocities**2).sum(axis=(1, 2))


def remove_rigid_motion(
    masses_me: ArrayLike, positions_bohr: ArrayLike, velocities_au: ArrayLike
) -> np.ndarray:
    m = np.asarray(masses_me, dtype=float)
    x = np.asarray(positions_bohr, dtype=float)
    v = np.asarray(velocities_au, dtype=float)
    total = m.sum()
    v = v - ((m[None, :, None] * v).sum(axis=1) / total)[:, None, :]
    r = x - ((m[None, :, None] * x).sum(axis=1) / total)[:, None, :]
    angular = (m[None, :, None] * np.cross(r, v)).sum(axis=1)
    r2 = (r**2).sum(axis=2)
    inertia = (m[None, :] * r2).sum(axis=1)[:, None, None] * np.eye(3) - np.einsum(
        "a,nai,naj->nij", m, r, r
    )
    omega = np.einsum("nij,nj->ni", np.linalg.pinv(inertia, rcond=1e-10), angular)
    return v - np.cross(omega[:, None, :], r)


def sample_wigner(
    masses_amu: ArrayLike, coords_bohr: ArrayLike, frequencies_cm1: ArrayLike,
    modes_mass_weighted: ArrayLike, *, n_samples: int, temperature_K: float,
    low_frequency_cutoff_cm1: float, rng: np.random.Generator,
) -> WignerSamples:
    masses = np.asarray(masses_amu, dtype=float) * DALTON_IN_ME
    coords = np.asarray(coords_bohr, dtype=float)
    freqs = np.asarray(frequencies_cm1, dtype=float)
    modes = np.asarray(modes_mass_weighted, dtype=float)
    natom = len(masses)
    sampled = freqs >= low_frequency_cutoff_cm1
    omega = freqs[sampled] / HARTREE_IN_CM1
    l = modes[:, sampled]
    sigma_q, sigma_p = mode_widths(omega, temperature_K)
    q = rng.standard_normal((n_samples, omega.size)) * sigma_q
    p = rng.standard_normal((n_samples, omega.size)) * sigma_p
    root = np.sqrt(np.repeat(masses, 3))
    positions = coords[None] + ((q @ l.T) / root).reshape(n_samples, natom, 3)
    raw_velocities = ((p @ l.T) / root).reshape(n_samples, natom, 3)
    velocities = remove_rigid_motion(masses, positions, raw_velocities)
    kinetic_before = _kinetic(masses, raw_velocities)
    kinetic_after = _kinetic(masses, velocities)
    mean_per_mode = 0.5 * omega * _occupation_factor(omega, temperature_K)
    return WignerSamples(
        positions_bohr=positions,
        velocities_au=velocities,
        q=q,
        p=p,
        harmonic_energy_hartree=0.5 * (p**2 + (omega * q) ** 2).sum(axis=1),
        kinetic_energy_hartree=kinetic_after,
        removed_kinetic_energy_hartree=kinetic_before - kinetic_after,
        sampled_modes=sampled,
        expected_mean_energy_hartree=float(mean_per_mode.sum()),
        expected_energy_std_hartree=float(np.sqrt((mean_per_mode**2).sum())),
    )
```

  `modes_mass_weighted` from `harmonic_analysis` is orthonormal in amu-weighted space. A unit vector in mass-weighted space is the same whether the masses are in amu or in electron masses, because only the norm scales. So using `root` in electron masses is consistent with ω in a.u.
