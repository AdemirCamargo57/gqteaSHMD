**Interfaces:**

- Produces:
  - **`RunSettings.energy_jump_limit_au: float | None = None`.** The library default is `None`, which means off, so every direct `RunSettings` user keeps its behaviour.
  - **`DynamicsStageSection.energy_jump_limit_eV: float = 0.1`**, which must be > 0 and finite. To switch the check off, set a large value; TOML has no null.
  - **`run_settings` maps it.**
  - **`TrajectoryOutcome.ELECTRONIC_DISCONTINUITY = "electronic_discontinuity"`.**
  - **The rejection signal name `"energy"`.**
  - **`DynamicsStage.version = 2`.** Existing projects then get the stale error and need `--rerun-from dynamics`.
  - **The fake-backend fault `energy_jump`.** It shifts every returned energy by `ENERGY_JUMP_SHIFT_EH = 0.01` Eh (0.272 eV).
  - **`run_our_trajectory(..., energy_jump_limit_eV: float | None = None)`.**
- **The rule:** after a successful (sub)step, `jump = |record.e_total - E_prev|`, where `E_prev` is the E_tot of the last accepted record, or of the t = 0 record.
  - If the limit is set and `not jump <= limit`, the step is rejected with signal `"energy"` and halved like the other signals.
  - At the smallest step a persisting jump ends the trajectory with `electronic_discontinuity`.
- **The signal order:** `electronic` (exception) > `overlap` > `energy` > `rung`. So a jump together with a rung change at the smallest step ends the trajectory; it is not accepted with a flag.

```python
    def _energy_jump(
        self, state: TrajectoryState, record: StepRecord, progress: Progress
    ) -> float | None:
        """|E_tot - E_tot(previous record)| if it exceeds energy_jump_limit_au, else None."""
        limit = self.settings.energy_jump_limit_au
        if limit is None:
            return None
        previous = progress.last_e_total_au
        if previous is None:  # a restart written before this field existed
            previous = float(
                state.snapshot.energies[state.active] + kinetic_energy(state.v, self.model.masses)
            )
        jump = abs(float(record.e_total) - previous)
        return None if jump <= limit else jump
```

```python
class Rung:
    """One attempt of the SA-CASSCF ladder.

    start: "previous" (the previous geometry's orbitals, skipped without them), "scf" (the SCF
    orbitals) or "previous_or_scf". conv_tol/conv_tol_grad: None = the [electronic.casscf]
    value; a number loosens it (max(user, rung)), never tightens it.
    """

    name: str
    start: str
    spin_shift: float
    macro_factor: int
    conv_tol: float | None = None
    conv_tol_grad: float | None = None


LADDER: tuple[Rung, ...] = (
    Rung("previous orbitals", "previous", 0.0, 1),
    Rung("SCF orbitals", "scf", 0.0, 1),

)
EXTRA_RUNG_NAMES: tuple[str, ...] = tuple(r.name for r in EXTRA_RUNGS)


def check_extra_rungs(names: Iterable[str]) -> tuple[str, ...]:
    chosen = tuple(names)

    return chosen
```
