**Goal:** Extend `gqteashmd.dynamics` (P7a-1) so it runs surface hopping with spin–orbit coupling in the diagonal representation. The parts are:
- linear vibronic coupling (LVC) models read from SHARC's `V0.txt` + `LVC.template`;
- the spin expansion of triplets into M_s components;
- the MCH→diagonal matrix U, carried in the state and the restart with phase continuity;
- gradients in the diagonal basis (nuclear gradient tensor transformation);
- local diabatization (`coupling = "overlap"`);
- energy-based selection of gradients and couplings (`eselect`);
- population ensembles through `gqteashmd model-dynamics`.

It is validated against our exact wavepacket solvers and against SHARC 4.1 run as a black box.

## Method reference (binding definitions; every task uses these)

Notation: N_exp is the number of spin-expanded MCH states and n_m the number of states of multiplicity m. Indices α, β run over MCH states and a, b over diagonal states. λ is the active **diagonal** state. All matrices are N_exp × N_exp unless stated.

1. **Spin expansion and canonical order** (manual §8.28). A model has state counts `(n_1, n_2, n_3)`, the singlets, doublets and triplets. **Only singlets and triplets are allowed** (n_2 = 0); counts longer than 3, or with doublets, raise `ValueError`.
   - A triplet state contributes three components, M_s = −1, 0, +1.
   - The order puts the state index innermost, then M_s, then the multiplicity: S0…S(n_1−1), then T1…T(n_3) with M_s = −1, then the same with M_s = 0, then with M_s = +1.
   - N_exp = n_1 + 3 n_3. Labels follow `core.states` (`S0`, `T1`); an expanded triplet label is written `T1(-1)`, `T1(0)`, `T1(+1)`.
2. **LVC Hamiltonian** (manual §8.18, eqs. 8.107 ff.; files §6.4.1).
   - **Normal coordinates.** Q_i = √ω_i Σ_{A,k} K_{(A,k),i} √M_A (r_{A,k} − r^ref_{A,k}), with K the orthogonal 3N × 3N matrix of mass-weighted normal modes (columns = modes) and M_A in electron masses. A mode with ω_i = 0 (translation, rotation) has Q_i ≡ 0.
     - The derivative is ∂Q_i/∂r_{A,k} = √ω_i K_{(A,k),i} √M_A.
     - The reference potential is V0 = Σ_i ω_i Q_i² / 2.
   - **Spin-free diabatic block** of multiplicity m (one n_m × n_m real symmetric matrix, shared by its M_s components):
     - V^(m)_αα = V0 + ε^(m)_α + Σ_i κ^(m)_{α,i} Q_i;
     - V^(m)_αβ = Σ_i λ^(m)_{αβ,i} Q_i for α ≠ β.

     A `lambda` entry given for (α, β) also sets (β, α).
   - **Diabatic SOC.** Σ is a constant complex Hermitian N_exp × N_exp matrix in the canonical order, taken from `SOC R` + i `SOC I` (absent: Σ = 0).
     - Non-Hermitian input with max |Σ − Σ†| > 1e-8 Eh raises `ValueError`; otherwise Σ is symmetrised as (Σ + Σ†)/2.
     - `spin_orbit = False` sets Σ = 0 (SHARC's `nospinorbit`).
3. **MCH quantities of the LVC model.**
   - **Eigenvectors.** For each multiplicity, V^(m) = W^(m) diag(E^(m)) W^(m)ᵀ with eigenvalues ascending. The sign of each column follows the P7a-1 `DiabaticModel` rule:
     - aligned to `previous.vectors` if given;
     - otherwise the largest-|component| is positive.
   - **Expansion.** T is the block-diagonal N_exp × N_exp real orthogonal matrix with W^(m) on every (m, M_s) block in canonical order. E is the expanded vector of spin-free MCH energies.
   - **Snapshot fields.**
     - `energies` = E;
     - `hamiltonian` H^MCH = diag(E) + Tᵀ Σ T (complex);
     - `gradients`: g_α = (W^(m)ᵀ ∂V^(m) W^(m))_αα, the same for every M_s component;
     - `nacs`: K_αβ = (W^(m)ᵀ ∂V^(m) W^(m))_αβ / (E_β − E_α) within one (m, M_s) block, and 0 between blocks (different multiplicity or M_s);
     - `vectors` = T;
     - `overlaps` S_βα = ⟨ψ_β(t)|ψ_α(t+Δt)⟩ = (T_previousᵀ T)_βα when `previous` is given, else `None`.
   - **Derivatives.** ∂V^(m)/∂r = Σ_i (ω_i Q_i 𝟙 + diag(κ^(m)_{·,i}) + Λ^(m)_i) ∂Q_i/∂r, where Λ^(m)_i is the symmetric matrix of the λ entries of mode i.
   - **Degeneracy.** |E_β − E_α| < 1e-12 inside one (m, M_s) block raises the P7a-1 degeneracy `ValueError`; degeneracies between blocks are allowed.
4. **Diagonal basis and U** (manual eqs. 8.129, 8.135–8.138; ruling R1, R2).
   - **Identity case.** If H^MCH has no non-zero off-diagonal element and there is no previous U, then U = `None`. This means U ≡ I in MCH order, with E^diag = Re diag(H^MCH).
   - **Otherwise:**
     1. eigh: H^MCH = U diag(E) U† with eigenvalues ascending (the diagonal states are ordered by energy, §8.28).
     2. **Phase and subspace tracking against U_prev** (the identity when U_prev is `None` but H has off-diagonals at the first step, see below). Group the ascending eigenvalues into degenerate blocks B: consecutive eigenvalues with E_{b+1} − E_b ≤ 1e-10 Eh are chained into one block. For each block form M = U[:,B]† U_prev[:,B] with SVD M = X Σ Yᴴ, and set U[:,B] ← U[:,B] X Yᴴ. A 1 × 1 block with |M| < 1e-14 is left unchanged.
     3. **No previous U at all** (t = 0): make the largest-|component| of each column real and positive instead.
     4. E^diag_a = Re (U† H^MCH U)_aa.

     This is our exactly unitary form of the manual's projection P_βa = V_βa δ(E_β − E_a) of eq. 8.138.
   - **Active MCH state** (manual eq. 8.143): `mch_state(u, λ)` = argmax_α |U_αλ| (lowest index on ties); with U = `None` it is λ.
5. **Gradient tensor and diagonal gradients** (manual §8.11.1, eqs. 8.49–8.50; ruling R3).
   - **MCH tensor** (real symmetric, n × n × f): G^MCH_αα = g_α and G^MCH_αβ = (E_β − E_α) K_αβ, with E the spin-free energies. This is ⟨α|∂Ĥ_SF|β⟩.
   - **Transformation** (`gradient_transformation`):
     - `"ngt"` (default): G^diag = U† G^MCH U, component by component;
     - `"none"` (SHARC's `nogradcorrect`, for comparison only): the off-diagonal terms of G^MCH are set to 0 first.

     With U = `None`, G^diag = G^MCH (no arithmetic).
   - **Diagonal gradient** g^diag_a = Re G^diag_aa. **Diagonal NAC** K^diag_ab = G^diag_ab / (E^diag_b − E^diag_a) for a ≠ b, with |E^diag_b − E^diag_a| < 1e-12 giving the zero vector.
   - **Exactness check.** For constant diabatic SOC, g^diag_a = ∂E^diag_a/∂q exactly (Hellmann–Feynman), which the finite-difference tests assert.
6. **Energy-based selection** (`eselect_Eh`; manual eqs. 8.150–8.151; ruling R5). With ε = `eselect_Eh` and a reference energy E_ref:
   - g_α is kept if |E_ref − E_α| < ε; K_αβ is kept if both α and β satisfy this;
   - everything else is set to 0 in the gradients and NACs of the snapshot, as **one masked snapshot used everywhere in the step**: the gradient tensor, the propagation couplings and the hop direction;
   - `None` (the default) keeps everything.

   E_ref is E^diag_λ of the active state at that geometry:
   - **At q (time t):** λ after the previous step's hop.
   - **At q′, before the hop:** the old λ.
   - **After an accepted hop:** the snapshot at q′ is masked again around the new λ (the "second electronic-structure call"), and that masked snapshot gives a′.
7. **Propagation in the diagonal basis** (manual §8.33, eqs. 8.185–8.199). The substep fractions s_m, m = 1…N_s, are those of the P7a-1 erratum (`"midpoint"`: (m − ½)/N_s; `"endpoint"`: m/N_s), with δ = Δt/N_s.
   - **`coupling = "nacdr"`:** R^MCH = Π_m exp(−i (H(s_m) − i 𝒯(s_m)) δ), where H(s) = (1 − s) H^MCH(t) + s H^MCH(t+Δt) and 𝒯 is the P7a-1 coupling matrix v·K in the chosen interpolation.
   - **`coupling = "overlap"`** (local diabatization):
     - H_tra = S H^MCH(t+Δt) S†, with S the snapshot overlaps at t+Δt;
     - R^MCH = S† Π_m exp(−i H̃(s_m) δ), with H̃(s) = (1 − s) H^MCH(t) + s H_tra;
     - no NACs are used.
   - **Diagonal propagator.** R^diag = U(t+Δt)† R^MCH U(t) (U = `None` counts as I), and c^diag(t+Δt) = R^diag c^diag(t).
   - **Fast path.** If U(t) = U(t+Δt) = `None` and the coupling is `"nacdr"`, the P7a-1 `propagate` is called unchanged with E = Re diag(H^MCH). This keeps the results bit-identical.
   - **Products and substeps.** Products are ordered with later substeps on the left. The factors are built by one batched `eigh` of the Hermitised substep matrices, as in P7a-1. The substep start amplitudes are returned only on the fast path (they are needed only by `"fssh"`).
8. **Hopping** (manual §8.29): the P7a-1 `"sharc"` formula with R^diag and c^diag. **`hopping = "fssh"`** is defined only in the MCH basis with NACs:
   - `DynamicsOptions` rejects it together with `coupling = "overlap"`;
   - the driver raises `ValueError("hopping = 'fssh' needs the MCH basis (no spin-orbit coupling); use 'sharc'")` when U is not `None`. The check is made at `initial_state` and at every step.
9. **Velocity adjustment** (ruling R4). ΔE = E^diag_j − E^diag_λ at q′.
   - **`parallel_vel`:** the P7a-1 rule.
   - **`parallel_nac`:** u = Re K^diag_λj from the masked snapshot at q′. If max |Im K^diag_λj| > 1e-10 · max(1, max |K^diag_λj|), raise `ValueError("parallel_nac needs a real coupling vector; with spin-orbit coupling use parallel_vel")`. With U = `None`, u is `snapshot.nacs[λ, j]` exactly (P7a-1).
   - **Frustrated hops:** keep or reflect as in P7a-1, with this u.
10. **Decoherence:** P7a-1 EDC (both conventions) applied to c^diag with E^diag and K after the hop.
11. **Step order** (replaces P7a-1 Method reference 8; the hop is still after the velocity completion). From the state (q, v, c^diag, λ, snapshot, U):
    1. Mask the state's snapshot around E^diag_λ(q) (item 6), then a = −M⁻¹ g^diag_λ.
    2. q′ = q + vΔt + ½aΔt².
    3. snap′ = model.evaluate(q′, previous=snapshot).
    4. (E^diag′, U′) = diagonal basis of snap′.hamiltonian against U (item 4).
    5. Mask snap′ around E^diag′_λ (old λ), then G^diag′; v′ = v + ½(a − M⁻¹ g^diag′_λ)Δt.
    6. Propagate c^diag over [t, t+Δt] with the masked snapshots at t and t+Δt, v and v′, U and U′ (item 7), giving c′ and R^diag.
    7. Hopping probabilities from λ (item 8); draw ξ (always exactly one).
    8. If there is a target j: velocity adjustment (item 9). If accepted, λ ← j, and with `eselect_Eh` set, snap′ is masked again around the new λ.
    9. Decoherence on c′ (item 10).
    10. a′ = −M⁻¹ g^diag′_λ. It is recomputed from the stored state at the next step's (1), so it is not part of the state.
    11. Record, with E_tot = E^diag′_λ + ½v′ᵀMv′; drift check as in P7a-1.
12. **Initial state** (ruling R7). `initial_state(model, q0, v0, active, c0=None)`: `active` is an **MCH** state index (expanded, canonical order) and `c0`, if given, is in the MCH basis.
    - With U0 from item 4 (no previous U): c^diag = U0† c^MCH (c^MCH = e_active when `c0` is absent), and λ = argmax_a |c^diag_a|² (lowest index on ties).
    - With U0 = `None` this is the P7a-1 behaviour.
13. **Populations** (manual §8.5, per trajectory and step):
    - diagonal classical δ_aλ; diagonal quantum |c^diag_a|²;
    - MCH classical |U_αλ|²; MCH quantum |(U c^diag)_α|²;
    - spin-summed MCH populations: the sum over the M_s components of each (multiplicity, state).

    U = `None` means U = I.
14. **Restart format 2** (ruling R8). The format adds U (`has_u`) and the snapshot overlaps (`has_overlaps`) to the P7a-1 contents. Version 1 files stay readable with U = `None`, provided their Hamiltonian has no off-diagonal element (otherwise `ValueError`). Continuing is bit-identical, also with SOC and hops.
15. **LVC Wigner initial conditions at T = 0.** For each mode with ω_i > 0, draw Q_i, P_i ~ N(0, ½) independently (the ground-state Wigner function of H_i = ω_i (Q_i² + P_i²)/2). Then:
    - r = r_ref + Σ_i K_{·,i} Q_i / (√ω_i √M);
    - v = Σ_i K_{·,i} √ω_i P_i / √M (componentwise in the masses).

    Modes with ω_i = 0 get Q = P = 0. Draw order: for each sample, the modes in increasing index, Q then P.

### Rulings (made in this plan; the owner can overturn them at plan review)

- **R1 — Ordering.** Diagonal states are energy-ordered whenever H^MCH has off-diagonal elements (manual §8.28). When it is exactly diagonal, the MCH order is kept with U = `None`. *Why:* this keeps P7a-1 (and singlet-only LVC) bit-identical, and it is the existing P7a-1 test "unsorted diagonal keeps MCH order".
- **R2 — Phase tracking.** We use a polar factor over degenerate blocks, not a pure phase. *Why:* the triplet M_s components are exactly degenerate without SOC, and U is only defined up to a unitary mixing inside such a block. The polar factor is the exactly unitary closest correction (this closes the P7a-1 deferred item about a degenerate-subspace rule).
- **R3 — G^MCH uses the spin-free energies E,** not diag H^MCH (which the manual writes). *Why:* this makes the transformation exact for constant diabatic SOC. The two agree when the diagonal of Tᵀ Σ T vanishes, which is true for every fixture here; the SHARC comparison measures it.
- **R4 — `parallel_nac` with a complex diagonal NAC is refused; `fssh` only in the MCH basis.** *Why:* the manual does not say how SHARC makes a complex vector real, and `parallel_vel` is SHARC's standard with SOC. Revisit with a black-box measurement if ever needed.
- **R5 — `eselect` masks one snapshot used everywhere in the step.** *Why:* this is how a backend that does not compute the deselected quantities behaves (P7b). With ε larger than every gap the results are bit-identical to `None` (tested).
- **R6 — LVC file scope.**
  - **Read:** the V0 path line, the states line, `epsilon`, `kappa`, `lambda`, `SOC R`/`SOC I`, `DMX/DMY/DMZ R/I` (stored, unused in dynamics) and `Multipolar Density Fit` (skipped by its count: no point-charge embedding).
  - **Refused:** `gamma` and `lambda_soc` with a count > 0, because the manual shows only the count line, not the entry format.
  - **Not used:** `LVC.resources`. Our model always diagonalises, does no Kabsch alignment and does no atom permutation.
- **R7 — Initial state.** It is given as an MCH state, and λ is the diagonal state with the largest weight.
- **R8 — Restart version 1** is accepted only without off-diagonal H (P7a-1 files never had any).
- **R9 — Ensemble averages.** A trajectory that ends with `energy_drift` is excluded from all ensemble averages (and counted). *Why:* an average over a changing set of trajectories mixes populations of different ensembles.
- **R10 — Overlaps for every model.** `DiabaticModel` (Tully, 2D) also returns overlaps (S = W_prevᵀ W after sign alignment), so `coupling = "overlap"` runs on the P7a-1 models and can be checked against the exact 1D solver.
