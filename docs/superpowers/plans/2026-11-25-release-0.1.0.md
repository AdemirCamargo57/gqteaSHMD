# Release 0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release gqteashmd 0.1.0: one version source, a build stamp that makes a normal install record its commit, an exact lock file, release notes and refreshed documents, a clean-install gate, and the tag.

**Architecture:** The version stays in `src/gqteashmd/__init__.py` and hatchling reads it from there. A hatchling build hook (`hatch_build.py`) writes `gqteashmd/_build.py` into every wheel (not into editable installs); a new standard-library module `gqteashmd/build_info.py` resolves the commit from the live checkout first, then from the stamp, and feeds `provenance.json` and `gqteashmd --version`. A shell script plus a small Python checker run the clean-install gate in `~/release_check/`. No stage, input key, output format or fingerprint changes.

**Tech Stack:** Python 3.12, hatchling (build hook API), conda (explicit lock), git, bash, pytest.

**Spec:** [docs/superpowers/specs/2026-11-25-release-0.1.0-design.md](../specs/2026-11-25-release-0.1.0-design.md) (owner decisions 1-5 in its section 0). The spec is binding; this plan argues from it. Where this plan's rulings differ, they are listed below.

## Plan rulings

- **PR1 (spec 5.1, "at the first failing one"):** the script stops at the first failure of the set-up checks 1-3 (version, clean tree, clone, build, environment); checks 4-5 (the version line, pip-installed runtime packages, the run, `analysis.json`, provenance) are all evaluated, written to `report.json` together, and the script then prints PASS or FAIL. A FAIL lists every failing check, which helps more than the first one alone. Cost if wrong: none (the gate still fails on any failure).
- **PR2 (spec 2.7, the hook test):** the hook is tested by building with hatchling's PEP 517 functions (`hatchling.build.build_wheel` / `build_editable`) on a copy of the working tree in `tmp_path`, committed into a fresh git repository there. A clone of the repository would test only committed code. Cost if wrong: none.
- **PR3 (spec 5.1):** the script's base directory is `${RELEASE_CHECK_ROOT:-$HOME/release_check}/<VERSION>`, so a trial run (Task 3) does not occupy `~/release_check/0.1.0`. Cost if wrong: none.
- **PR4 (spec 2.1):** `tests/test_package.py` stops hard-coding the version: it checks that `__version__` is a PEP 440 release or `.devN` version and equals the installed metadata version. So the bump to `0.2.0.dev0` (step R7) needs no test edit, and a stale editable install (metadata not refreshed after a version change) fails loudly. Cost: after any version change the development environment needs `pip install -e . --no-deps` (documented in `docs/development.md`, Task 4).

```python
import types

def _stamp(monkeypatch, **values):
    module = types.ModuleType("gqteashmd._build")
    for name, value in values.items():
        setattr(module, name, value)
    monkeypatch.setitem(sys.modules, "gqteashmd._build", module)

    subprocess.run(["git", "init", "-q", str(path)], check=True)
    (path / "f.txt").write_text("x\n")
    subprocess.run([*git, "add", "f.txt"], check=True)
```

```python
"""Which commit this installation of gqteashmd comes from (spec 2026-11-25-release-0.1.0, 2.3-2.5).

A source checkout (an editable install) answers from git directly. A wheel answers from the
build stamp `gqteashmd/_build.py` that `hatch_build.py` writes into it. Standard library only:
`gqteashmd.cli` imports this module.
"""

from __future__ import annotations

import importlib
import subprocess
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Literal

from gqteashmd import __version__

CommitSource = Literal["git", "build"]


@dataclass(frozen=True)
class CommitInfo:
    commit: str | None
    dirty: bool | None
    source: CommitSource | None
    build_time: str | None


UNKNOWN = CommitInfo(None, None, None, None)


def _checkout_root() -> Path:
    """The repository root if this module is imported from a source checkout (src layout)."""
    return Path(__file__).resolve().parents[2]


def _git(root: Path, *args: str) -> str | None:
    try:
        out = subprocess.run(
            ["git", "-C", str(root), *args], capture_output=True, text=True, timeout=5, check=True
        )
    except (OSError, subprocess.SubprocessError):
        return None
    return out.stdout.strip()


def _live_checkout() -> CommitInfo | None:
    root = _checkout_root()
    if not (root / ".git").exists():
        return None
    commit = _git(root, "rev-parse", "HEAD")
    if not commit:
        return None
    status = _git(root, "status", "--porcelain")
    return CommitInfo(commit, None if status is None else bool(status), "git", None)


def build_stamp() -> dict[str, Any] | None:
    """The stamp written into a wheel at build time; `None` if the package carries none."""
    try:
        module = importlib.import_module("gqteashmd._build")
    except ImportError:
        return None
    return {
        "commit": getattr(module, "COMMIT", None),
        "dirty": getattr(module, "DIRTY", None),
        "build_time": getattr(module, "BUILD_TIME", None),
    }


def commit_info() -> CommitInfo:
    """The live checkout first, then the build stamp, else nothing known."""
    live = _live_checkout()
    if live is not None:
        return live
    stamp = build_stamp()
    if stamp is None or not stamp["commit"]:
        return UNKNOWN
    dirty = stamp["dirty"] if isinstance(stamp["dirty"], bool) else None
    build_time = stamp["build_time"] if isinstance(stamp["build_time"], str) else None
    return CommitInfo(str(stamp["commit"]), dirty, "build", build_time)


def version_text() -> str:
    """The text of `gqteashmd --version`."""
    info = commit_info()
    if info.commit is None:
        return f"gqteashmd {__version__}"
    dirty = ", dirty" if info.dirty else ""
    return f"gqteashmd {__version__} (commit {info.commit[:7]}{dirty})"
```

```python
Each test copies the working tree's build inputs into tmp_path and builds there with hatchling's
PEP 517 functions, so the hook under test is the working tree's, committed or not.

import shutil
import subprocess
import sys
import zipfile
from datetime import datetime
from pathlib import Path

import pytest

pytestmark = pytest.mark.slow

ROOT = Path(__file__).resolve().parents[1]
STAMP = "gqteashmd/_build.py"


def _tree(tmp_path: Path) -> Path:
    # the tree and the build output are siblings, so a build never makes the tree dirty
    dest = tmp_path / "tree"
    dest.mkdir()
    for name in ("pyproject.toml", "hatch_build.py", "README.md", "LICENSE"):
        shutil.copy2(ROOT / name, dest / name)
    shutil.copytree(
        ROOT / "src",
        dest / "src",
        ignore=shutil.ignore_patterns("__pycache__", "*.egg-info", "_build.py"),
    )
    return dest


def _commit(dest: Path) -> str:
    git = ["git", "-C", str(dest), "-c", "user.name=t", "-c", "user.email=t@example.invalid"]
    subprocess.run(["git", "init", "-q", str(dest)], check=True)
    subprocess.run([*git, "add", "-A"], check=True)
    subprocess.run([*git, "commit", "-q", "-m", "c"], check=True)
    out = subprocess.run(
        ["git", "-C", str(dest), "rev-parse", "HEAD"], capture_output=True, text=True, check=True
    )
    return out.stdout.strip()


def _build(tree: Path, kind: str) -> Path:
    out_dir = tree.parent / "out"
    code = f"from hatchling.build import build_{kind}; print(build_{kind}({str(out_dir)!r}))"
    out = subprocess.run(
        [sys.executable, "-c", code], cwd=tree, capture_output=True, text=True, check=True
    )
    return out_dir / out.stdout.strip().splitlines()[-1]


def _stamp(wheel: Path) -> dict:
    with zipfile.ZipFile(wheel) as archive:
        text = archive.read(STAMP).decode("utf-8")
    namespace: dict = {}
    exec(text, namespace)
    return {k: namespace[k] for k in ("COMMIT", "DIRTY", "BUILD_TIME")}

    head = _commit(tree)
    stamp = _stamp(_build(tree, "wheel"))
    assert stamp["COMMIT"] == head and stamp["DIRTY"] is False
    assert datetime.fromisoformat(stamp["BUILD_TIME"]).utcoffset().total_seconds() == 0
    assert not (tree / "src" / "gqteashmd" / "_build.py").exists()  # source tree untouched

    (tree / "README.md").write_text("changed\n")

    assert stamp["COMMIT"] == head and stamp["DIRTY"] is True
```

```python
"""Hatchling build hook: write the build stamp into the wheel (release spec 2026-11-25, 2.2).

A wheel gets `gqteashmd/_build.py` with the commit, whether the tree was dirty, and the build
time (read by `gqteashmd.build_info`). Editable builds get nothing: they read the live checkout.
The source tree is never written; the stamp is a temporary file added with `force_include`.
"""

from __future__ import annotations

import subprocess
import tempfile
from datetime import UTC, datetime
from pathlib import Path
from typing import Any

from hatchling.builders.hooks.plugin.interface import BuildHookInterface

STAMP_TARGET = "gqteashmd/_build.py"


def _git(root: Path, *args: str) -> str | None:
    try:
        out = subprocess.run(
            ["git", "-C", str(root), *args], capture_output=True, text=True, timeout=10, check=True
        )
    except (OSError, subprocess.SubprocessError):
        return None
    return out.stdout.strip()


def stamp_text(root: Path, now: datetime) -> str:
    """The stamp module's text: `root` must be the top of a git checkout to get a commit."""
    commit: str | None = None
    dirty: bool | None = None
    top = _git(root, "rev-parse", "--show-toplevel")
    if top and Path(top).resolve() == root.resolve():
        commit = _git(root, "rev-parse", "HEAD") or None
        if commit is not None:
            status = _git(root, "status", "--porcelain")
            dirty = None if status is None else bool(status)
    return (
        '"""Build stamp, written by hatch_build.py when this wheel was built."""\n\n'
        f"COMMIT = {commit!r}\n"
        f"DIRTY = {dirty!r}\n"
        f"BUILD_TIME = {now.isoformat(timespec='seconds')!r}\n"
    )


class CustomBuildHook(BuildHookInterface):
    PLUGIN_NAME = "custom"

    def initialize(self, version: str, build_data: dict[str, Any]) -> None:
        if self.target_name != "wheel" or version == "editable":
            return
        self._stamp_dir = tempfile.TemporaryDirectory(prefix="gqteashmd-stamp-")
        path = Path(self._stamp_dir.name) / "_build.py"
        path.write_text(stamp_text(Path(self.root), datetime.now(UTC)), encoding="utf-8")
        build_data["force_include"][str(path)] = STAMP_TARGET

    def finalize(self, version: str, build_data: dict[str, Any], artifact_path: str) -> None:
        stamp_dir = getattr(self, "_stamp_dir", None)
        if stamp_dir is not None:
            stamp_dir.cleanup()
            self._stamp_dir = None
```

```python
"""Checks of the release clean-install gate (release spec 2026-11-25, section 5.1; plan PR1).

Run by tools/release/clean_install_check.sh with the development environment's Python. Standard
library only; never imported by gqteashmd. Every check is evaluated and written to report.json.
"""

from __future__ import annotations

import argparse
import json
import re
import sys
from pathlib import Path
from typing import Any

RUNTIME_PACKAGES = ("pydantic", "numpy", "scipy", "pyscf", "h5py", "geometric")
COMMIT_RE = re.compile(r"[0-9a-f]{40}")


def expected_version_line(version: str, commit: str) -> str:
    return f"gqteashmd {version} (commit {commit[:7]})"


def pip_installed_runtime(conda_list: list[dict[str, Any]]) -> list[str]:
    """Runtime dependencies that pip, not conda, installed (the lock file would miss them)."""
    return sorted(
        str(p["name"])
        for p in conda_list
        if p.get("name") in RUNTIME_PACKAGES and p.get("channel") == "pypi"
    )


def _last_run(provenance: dict[str, Any] | None) -> dict[str, Any]:
    if not isinstance(provenance, dict):
        return {}
    runs = provenance.get("runs")
    if not isinstance(runs, list) or not runs or not isinstance(runs[-1], dict):
        return {}
    return runs[-1]


def evaluate(
    *,
    version: str,
    commit: str,
    version_line: str,
    conda_list: list[dict[str, Any]],
    provenance: dict[str, Any] | None,
    analysis_exists: bool,
    run_exit: int,
) -> list[dict[str, Any]]:
    entry = _last_run(provenance)
    pip = pip_installed_runtime(conda_list)
    line = version_line.strip()
    items = [
        ("version_line", line == expected_version_line(version, commit), line),
        ("runtime_from_conda", not pip, pip),
        ("run_exit_code", run_exit == 0, run_exit),
        ("analysis_json", analysis_exists, analysis_exists),
        ("provenance_version", entry.get("gqteashmd") == version, entry.get("gqteashmd")),
        (
            "provenance_commit_source",
            entry.get("commit_source") == "build",
            entry.get("commit_source"),
        ),
        (
            "provenance_commit",
            bool(COMMIT_RE.fullmatch(commit)) and entry.get("git_commit") == commit,
            entry.get("git_commit"),
        ),
        ("provenance_clean", entry.get("git_dirty") is False, entry.get("git_dirty")),
    ]
    return [{"check": name, "passed": bool(ok), "value": value} for name, ok, value in items]


def _read_json(path: Path) -> Any:
    try:
        return json.loads(path.read_text(encoding="utf-8"))
    except (OSError, ValueError):
        return None


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--version", required=True)
    parser.add_argument("--commit", required=True)
    parser.add_argument("--version-line", required=True)
    parser.add_argument("--conda-list", type=Path, required=True)
    parser.add_argument("--provenance", type=Path, required=True)
    parser.add_argument("--analysis", type=Path, required=True)
    parser.add_argument("--run-exit", type=int, required=True)
    parser.add_argument("--out", type=Path, required=True)
    args = parser.parse_args(argv)
    conda_list = _read_json(args.conda_list)
    checks = evaluate(
        version=args.version,
        commit=args.commit,
        version_line=args.version_line,
        conda_list=conda_list if isinstance(conda_list, list) else [],
        provenance=_read_json(args.provenance),
        analysis_exists=args.analysis.is_file(),
        run_exit=args.run_exit,
    )
    passed = all(c["passed"] for c in checks)
    report = {"version": args.version, "commit": args.commit, "passed": passed, "checks": checks}
    args.out.write_text(json.dumps(report, indent=2) + "\n", encoding="utf-8")
    for c in checks:
        print(f"{'ok  ' if c['passed'] else 'FAIL'} {c['check']}: {c['value']}")
    print("PASS" if passed else "FAIL")
    return 0 if passed else 1


if __name__ == "__main__":
    sys.exit(main())
```

```bash
#!/usr/bin/env bash
# Clean-install check of a release (release spec 2026-11-25, section 5.1; plan PR1, PR3).
#
# Usage, in WSL with gqteashmd-dev active, from the repository:
#   tools/release/clean_install_check.sh VERSION [LOCK_FILE]
# Builds the wheel from a clean clone of HEAD, installs it (not editable) into a fresh
# environment created from the lock file, runs tools/release/water_check.toml through the
# analysis and checks the version line and provenance. Everything goes under
# ${RELEASE_CHECK_ROOT:-$HOME/release_check}/VERSION. Exit 0 and PASS when every check passes.
set -euo pipefail

version="${1:?usage: clean_install_check.sh VERSION [LOCK_FILE]}"
repo="$(git rev-parse --show-toplevel)"
lock="${2:-$repo/environment.lock.txt}"
base="${RELEASE_CHECK_ROOT:-$HOME/release_check}/$version"

fail() {
    echo "FAIL: $*" >&2
    exit 1
}

# `conda` is a shell function in an interactive shell; a script uses the executable it names
conda="${CONDA_EXE:-conda}"
command -v "$conda" >/dev/null || fail "conda not found: activate gqteashmd-dev"

# 1. the version at HEAD and a clean tree
head="$(git -C "$repo" rev-parse HEAD)"
source_version="$(git -C "$repo" show HEAD:src/gqteashmd/__init__.py \
    | sed -n 's/^__version__ = "\(.*\)"$/\1/p')"
[ "$source_version" = "$version" ] || fail "VERSION $version differs from __version__ $source_version at HEAD"
[ -z "$(git -C "$repo" status --porcelain)" ] || fail "the working tree of $repo is not clean"
[ -f "$lock" ] || fail "no lock file $lock"
lock="$(realpath "$lock")"
python -c "import hatchling" 2>/dev/null || fail "hatchling is missing: activate gqteashmd-dev"
[ ! -e "$base" ] || fail "$base exists; move it aside first"

# 2. a clean clone of HEAD and the wheel
mkdir -p "$base"
echo "clone $head into $base/src"
git clone --quiet "$repo" "$base/src"
git -C "$base/src" checkout --quiet "$head"
(cd "$base/src" && pip wheel . --no-deps --no-build-isolation --quiet -w "$base/dist")
wheel="$(ls "$base"/dist/gqteashmd-"$version"-*.whl)"
echo "built $wheel"

# 3. a fresh environment from the lock file, and the wheel installed into it
echo "create $base/env from $lock"
"$conda" create --yes --quiet -p "$base/env" --file "$lock" >/dev/null
"$conda" run -p "$base/env" pip install --no-deps --quiet "$wheel"
"$conda" list -p "$base/env" --json > "$base/conda_list.json"

# 4 and 5. the version line and a run, from outside the repository
mkdir -p "$base/project"
cp "$repo/tools/release/water_check.toml" "$repo/tools/release/water.xyz" "$base/project/"
cd "$base/project"
version_line="$("$conda" run -p "$base/env" gqteashmd --version)"
echo "version line: $version_line"
echo "run water_check.toml (log: $base/project/run.log)"
set +e
"$conda" run -p "$base/env" gqteashmd run water_check.toml > run.log 2>&1
run_exit=$?
set -e

# 6. every check into report.json, then PASS or FAIL
python "$repo/tools/release/release_checks.py" \
    --version "$version" --commit "$head" --version-line "$version_line" \
    --conda-list "$base/conda_list.json" \
    --provenance "$base/project/run/.gqteashmd/provenance.json" \
    --analysis "$base/project/run/07_analysis/analysis.json" \
    --run-exit "$run_exit" --out "$base/report.json"
```
